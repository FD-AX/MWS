# Основные моменты документации (официально от МТС, Drive 2026-09-01)

Источник: «Основные моменты документации.pdf» (папка кейса, ID 1uxriyZJh5U7f7C2krwBWfY6UFUccVAnu).
Восстановлены обрезанные заглавные буквы. Это ОФИЦИАЛЬНАЯ рубрика кейсодателя.

1. **Спецификация сериализации** — в обязательном порядке указывается модель
   входного и выходного потока данных (формат, схема, тип сериализации/десериализации).
2. **Привязка к источникам** — обязательно наличие прямой ссылки на Дата-каталог.
3. **Описание витрин данных** — для каждого поля витрины явно указывается признак
   обязательности (NOT NULL / NULLABLE).
4. **Типовые фильтры** — в документации фиксируются стандартные условия фильтрации,
   применяемые на этапе построения витрин и выгрузки.
5. **Сохранение структуры шаблона** — все разделы шаблона должны быть сохранены.
   При отсутствии обогащения, фильтрации или иных этапов обработки это явно
   прописывается формулировкой «не применимо».
6. **Инфраструктурные параметры** — обязательно указывается кластер Kafka для
   потоковых источников/приёмников.
7. **Хранение данных** — для всех файловых хранилищ прописывается полный путь
   в HDFS с указанием формата.
8. **Нормативно-справочная информация** — в описание каждой витрины включается
   перечень используемых справочников.
