# Описание витрины-агрегата TABLE_AGG_DEVICES

## Общие сведения

Агрегат по устройствам абонентов: ежемесячная сводка по вендорам устройств и регионам пользователей.

## Бизнес-требования

Название таблицы: TABLE_AGG_DEVICES

Кластер: CLUSTER

Схема: SCHEMA_CDM_NETS

## Системы-источники

IUM — IN-платформа (сбор событий интернет-трафика, звонков и SMS)

## Способ загрузки

Инкремент

## Регламент

Ежемесячно (1 раз в месяц)

## Глубина данных

С 01.05.2023
Обязательно загрузить исторические данные.

## 2. Структура данных CDM

Таблица: TABLE_AGG_DEVICES

| Номер | Поле | Тип данных | Описание | Комментарий |
|---|---|---|---|---|
| 1 | FIELD_REGION_NAME | string | Название региона | Определяется как последнее значение region_name за месяц для абонента: сначала по (lac, cell), затем fallback-логика (см. алгоритм). |
| 2 | FIELD_VENDOR_NAME | string | Наименование вендора устройства | substring(imei, 1, 8) = tac → vendor_name. |
| 3 | FIELD_USERS_CNT | bigint | Уникальное количество абонентов (IMSI) | count(distinct FIELD_IMSI) |
| 4 | FIELD_PROC_TS | timestamp | Дата/время создания агрегата | Метка обработки DAG |
| 5 | FIELD_BIZ_DATE | date | Бизнес-дата (1-е число месяца, за который формируется агрегат) | Пример: для периода 01.07.2023–31.07.2023 → 2023-07-01 |

## Алгоритм расчёта

Шаг 1. Выбор пользователей

Берутся все уникальные FIELD_IMSI из:

- TABLE_IUM_RAW_MS (SMS + звонки)
- TABLE_IUM_RAW_PS (GPRS) за период: FIELD_BIZ_DATE (месяц).

Шаг 2. Определение вендора

Для каждого FIELD_IMSI берётся FIELD_IMEI (последний по времени за месяц).

Извлекается tac = substring(imei, 1, 8).

Присоединяется FIELD_VENDOR_NAME по tac из TABLE_DEVICE_REF.

Шаг 3. Определение региона

Для каждого FIELD_IMSI за месяц:

Находится последняя запись с ненулевыми FIELD_LAC и FIELD_CELL_ID (по FIELD_TIME_STAMP).

Сопоставление с TABLE_BS_REF: приоритет: (lac, cell_id)

- по lac (последняя актуальная запись за месяц)
- по cell_id только для 4G (FIELD_CELL_GEN = 4)
- если lac = 0 → джойн только по cell_id (4G)
- если cell = 0 → джойн только по lac

Убираются дубли: на выходе — одна region_code на абонента.

Присоединение FIELD_REGION_NAME из TABLE_REGION_REF.

Шаг 4. Агрегация
Группировка по:

- FIELD_REGION_NAME
- FIELD_VENDOR_NAME
- FIELD_USERS_CNT = count(distinct FIELD_IMSI)
