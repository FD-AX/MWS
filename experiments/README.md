# Журнал экспериментов

Правила ведения (обязательные):
1. **Каждый прогон = запись в таблице** + детальный файл `EXP-NN-<slug>.md` по шаблону ниже.
2. Файл заводится **до** прогона (вопрос, конфигурация, ожидание) — цифры и вывод дописываются после. Гипотеза без ожидания = не эксперимент.
3. Сырые отчёты бенча остаются в `eval/night/` (или `eval/`), в файле эксперимента — только ссылка и выжимка.
4. Команда воспроизведения — обязательна в детальном файле.
5. Голд/базы менялись? — указать итерацию синтетики (см. CHANGELOG внизу): цифры разных итераций напрямую не сравниваются.
