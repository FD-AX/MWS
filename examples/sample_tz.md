# ТЗ: Поток SRC_RADIO_PM и витрина DM_CELL_QUALITY_DAILY

## 1. Общие сведения

Необходимо разработать поток загрузки счётчиков производительности радиосети из источника SRC_RADIO_PM и суточную витрину качества DM_CELL_QUALITY_DAILY для отдела оптимизации сети. Данные должны поставляться потребителям оперативно.

## 2. Источник данных

Источником являются файлы выгрузки OSS-системы в формате CSV, публикуемые на SFTP-сервере в каталоге /export/pm/. Файлы содержат следующие счётчики по каждой ячейке: CNT_TRAFFIC_UL, CNT_TRAFFIC_DL, CNT_AVAIL_NUM, CNT_AVAIL_DENOM, CNT_CONN_ATTEMPTS и т. д.

Выгрузка формируется на стороне OSS с почасовой гранулярностью. Ожидается большой объём данных.

## 3. Структура целевых таблиц

Витрина DM_CELL_QUALITY_DAILY содержит следующие поля:

| Поле | Тип | Источник / правило |
|---|---|---|
| CELL_ID | VARCHAR(64) | SRC_RADIO_PM.CELL_ID |
| REPORT_DATE | DATE | дата агрегации |
| TRAFFIC_TOTAL | DECIMAL(18,2) | CNT_TRAFFIC_UL + CNT_TRAFFIC_DL |
| AVAIL_PCT | DECIMAL(5,2) | CNT_AVAIL_NUM / CNT_AVAIL_DENOM * 100 |
| DROP_RATE | DECIMAL(5,2) | CNT_DROP_TOTAL / CNT_CONN_ATTEMPTS * 100 |
| REGION_CODE | VARCHAR(8) | |

## 4. Правила трансформации

Счётчики соты агрегируются с часового уровня до суточного суммированием. Показатель AVAIL_PCT рассчитывается по агрегированным за сутки значениям числителя и знаменателя. Значения DROP_RATE рассчитываются аналогично.

## 5. Регламент загрузки

Данные загружаются ежедневно и добавляются в витрину. При необходимости выполняется повторная загрузка за прошлые периоды.
