# Фронтенд аналитика (Streamlit, `app.py`)

Интерфейс «DocReview AI» (автор — Сокол Тимофей): загрузка PDF/DOCX/TXT/MD или вставка текста, сводка по
критичности, таблица и карточки замечаний с поиском и фильтрами, извлечённый текст, структура документа и
покрытие чек-листа, скачивание отчёта (markdown) и JSON.

## Как запускается

**В compose (рекомендуется)** — сервис `front`, http://localhost:15173. Работает в **режиме API**
(`TZR_API_URL=http://api:8080`): документ уходит в очередь, считается воркером на настроенной модели,
результат и версии документа сохраняются в истории (Postgres), на экране — прогресс по этапам конвейера.

```bash
docker compose -f deploy/docker-compose.yml up -d --build   # поднимает и front
```

**Локально без Docker** — режим «в процессе»: конвейер гоняется прямо из приложения.

```bash
pip install -r requirements.txt
streamlit run app.py          # «Быстрая» = детерминированный слой; «Полная с LLM» = по .env (TZR_* или задать TZR_API_URL)
```

Задай `TZR_API_URL=http://localhost:18080` — и локальный Streamlit тоже пойдёт через API.

## Как устроена стыковка

- `tz_review/api_client.py` — отправка документа (`POST /reviews`), ожидание (`GET /reviews/{id}` с прогрессом),
  сборка `ReviewResult` из ответа API. Рендер в `app.py` один и тот же для локального и API-режима.
- Контракт API — `services/api/API.md`; встроенный минимальный UI на http://localhost:18080/ использует те же ручки.
- В API-режиме извлечённый в приложении текст отправляется как markdown-файл с исходным именем: имя попадает в
  историю версий, сервис документов восстанавливает заголовки.

## Что подключено к API (04.09)

- Вкладка **«История проверок»** (и на экране загрузки, и на экране результата): последние проверки из
  `GET /reviews`, кнопка «Открыть» поднимает любую из истории; для открытого документа — версии и их ревью
  из `GET /documents/{hash}/history`.
- **👍/👎 по каждой находке** → `POST /findings/{id}/feedback` (ключ находки приходит из результата API).
- **Исходный PDF/DOCX уходит в API как есть** (`submit_review_file`): таблицы и заголовки восстанавливает
  docs-сервис; вкладки «Текст документа» и «Структура» показывают нормализованный markdown из истории
  (`GET /documents/{hash}/text`), а не плоское извлечение.
