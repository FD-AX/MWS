# Фронтенд аналитика (внешняя сборка)

Сюда кладётся собранный фронтенд (статические файлы: `index.html`, `assets/…`) — `front/dist/`.
Сервис `front` в compose (профиль `front`) отдаёт его через nginx на http://localhost:15173 и
проксирует вызовы `/api/*` в наш API, так что фронту не нужен CORS и абсолютные адреса:

```bash
# положить сборку в front/dist, затем:
docker compose -f deploy/docker-compose.yml --profile front up -d front
```

Контракт API — `services/api/API.md` (те же ручки, что использует встроенный UI на http://localhost:18080/).
Во фронте базовый адрес API задавать как `/api` (nginx перепишет в `http://api:8080`).

Если сборка — Vite/React: `npm run build` → скопировать содержимое `dist/` сюда. Исходники фронта можно держать
в `front/src/` этого репозитория или в отдельном репозитории — сборка в любом случае коммитится сюда как `front/dist/`,
чтобы «скачал и запустил» работало без Node.
