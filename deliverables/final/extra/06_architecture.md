# DocReview AI: архитектура контура и конвейера

## Контур (docker compose)

```
аналитик ─ front (Streamlit :15173) ─┐
                                     ├─► api (FastAPI :18080) ─► RabbitMQ review.jobs ─► worker (tz_review)
                                     │                              │                      │
                                     │                              ▼                      ▼
                                     │                           docs (:18081)         gpt-oss-120b (vLLM)
                                     │                        pdf/docx → markdown
                                     └─ история ◄── Postgres (документы, ревью, находки, 👍/👎)
                                        метрики ◄── Prometheus / Grafana
```

Надёжность: durable-очередь, DLQ `review.dead`, ack только после записи результата, идемпотентность по `(doc_hash, config_hash)`, ретраи LLM с jitter.

Модель подключается через `TZR_BASE_URL` / `TZR_BACKEND`. В демонстрации используется RunPod H100 + vLLM; при пилоте тот же OpenAI-совместимый сервис можно развернуть во внутреннем контуре МТС.

## Восемь механизмов конвейера

| Механизм | Зачем | Число |
|---|---|---|
| Правила без модели | шаблон МТС, пустые разделы, TBD / «и т.д.» | нарушения шаблона 6/6, 0 ложных |
| Граф сущностей | поля, таблицы, ссылки по номеру и имени | синтетика 2→5/12, 0 вызовов модели |
| Чеклист 27 слотов | 19 полноты + 8 пунктов МТС; NA до модели | ложных 11→7, UNKNOWN 10→0 |
| Согласованность разделов | инкремент vs полная перезагрузка, UTC vs пояса | класс противоречий 14/15 на GPT |
| Взгляд разработчика | «что спрошу при реализации» | без него −45 попаданий на 20 прогонах |
| Фильтр заглушек | обезличивание ≠ дефект | вопросы о заглушках 5→0 |
| Верификация цитат | в отчёт попадает текст документа | заякоренность 83–100%; EXP-24: 4→17/28 |
| Критик | ранжирование, θ=4; обязательные слоты не отсекаются | v3official: 9→12/13 контролируемых дефектов |

Выключено по EXP-19/21: семантическая энтропия и зонд неоднозначности на 120b.

## Что сознательно не делаем

- Triton Inference Server — дни настройки, качества не добавляет.
- Интеграция с Confluence — вне скоупа кейса.
- Fine-tuning — нет размеченных корректировок разработчиков.
- «Одна большая модель на всё» — детерминированные слои бесплатны, LLM нужна только в LLM-этажах.
