# EXP-24: спасение отброшенных цитат без потери дословности

Продуктовое правило: в отчёт аналитику попадает текст документа, а не пересказ модели. Substring-проверка это гарантирует, но хрупка: неразрывный дефис, пунктуация, составные цитаты и артефакты конвертации молча выбрасывали настоящие находки.

## Вопрос

Сколько из отброшенных цитат — жертвы хрупкости, сколько — честный перифраз, и что из первых спасается, не ослабляя гарантию «цитата = текст документа»?

## Метод

Реплей 58 отброшенных находок (28 уникальных цитат) из сырых JSON бенча **без новых вызовов модели**. Каждый спасённый якорь вычитан глазами.

## Было → стало

| | Записей (58) | Уникальных цитат (28) |
|---|---|---|
| Верифицируются до правок | 4 | 4 |
| После правок | **41** | **17** |
| из них точечные правки (дефис, пунктуация, окно, вес отрезка) | 16 | 10 |
| из них нечёткий якорь (порог 0.70, якорь = строка документа) | 13 | 2 |
| из них уникальная короткая цитата | 8 | 1 |
| Отброшены правильно (перифраз / перевод / список) | 17 | 11 |

Ложных спасений нет. Recall по голду **не вырос**: спасённые находки дублируют уже пойманные дефекты. Выигрыш — заякоренность и отсутствие молчаливых потерь в отчёте.

## Вывод для продукта

Гарантия «замечание без цитаты — не замечание» сохранена на всех ступенях: в отчёт идёт фрагмент документа, не текст модели. Нечёткий якорь — последний рубеж с порогом по измеренному зазору (верные 0.72–0.98, ошибочные ≤ 0.52).
