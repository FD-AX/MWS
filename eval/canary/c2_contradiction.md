# ТЗ: Поток TABLE_CANARY_B

## Источник данных

Kafka-топик TOPIC_CANARY_B, JSON-сообщения. Поля: FIELD_KEY (string), FIELD_TS (timestamp, UTC), FIELD_AMOUNT (decimal(12,2)).

## Структура целевых таблиц

Таблица TABLE_CANARY_B: FIELD_KEY (string, ключ вместе с FIELD_TS), FIELD_TS (timestamp), FIELD_AMOUNT (decimal(12,2)). Партиционирование по дате из FIELD_TS.

## Правила трансформации

Сообщения пишутся в таблицу без преобразований. Дубликаты по (FIELD_KEY, FIELD_TS) отбрасываются, остаётся первое прочитанное сообщение. Сообщения с FIELD_AMOUNT = NULL отбрасываются в таблицу ошибок ERR_CANARY_B.

## Регламент загрузки

Загрузка идёт непрерывно (стриминг); данные доступны потребителям не позднее чем через 15 минут после появления в топике.

## Контроль качества

Каждый час сверяется число прочитанных из топика сообщений и число записанных строк плюс отбракованные; при расхождении больше 0 — алерт. Данные за час H доступны потребителям не позднее H+4 часа.
