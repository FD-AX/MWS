# ТЗ: Поток TABLE_CANARY_A

## Источник данных

Файлы CSV на SFTP, каталог /export/a/. Поля: FIELD_ID (bigint), FIELD_VALUE (decimal(10,2)), FIELD_EVENT_DATE (date).

## Структура целевых таблиц

Таблица TABLE_CANARY_A: FIELD_ID (bigint, ключ вместе с FIELD_EVENT_DATE), FIELD_VALUE (decimal(10,2)), FIELD_EVENT_DATE (date, партиция).

## Правила трансформации

Данные переносятся из файла в таблицу без преобразований. Записи с пустым FIELD_ID отбрасываются в таблицу ошибок ERR_CANARY_A.

## Регламент загрузки

Данные загружаются ежедневно и добавляются в таблицу.

## Контроль качества

Сверка числа строк файла и загруженных строк с учётом отбракованных; расхождение больше 0 строк — алерт.
