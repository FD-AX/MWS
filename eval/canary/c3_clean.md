# ТЗ: Поток TABLE_CANARY_C

## Источник данных

Файлы CSV на SFTP, каталог /export/c/, маска c_YYYYMMDD.csv, кодировка UTF-8. Поля: FIELD_ID (bigint), FIELD_NAME (string), FIELD_SNAPSHOT_DATE (date).

## Структура целевых таблиц

Таблица TABLE_CANARY_C: FIELD_ID (bigint), FIELD_NAME (string), FIELD_SNAPSHOT_DATE (date, партиция). Ключ: (FIELD_ID, FIELD_SNAPSHOT_DATE).

## Правила трансформации

Данные переносятся без преобразований. Записи с пустым FIELD_ID отбрасываются в таблицу ошибок ERR_CANARY_C с кодом EMPTY_KEY. Значения NULL в FIELD_NAME сохраняются как NULL.

## Регламент загрузки

Инкремент по дате из имени файла: загружаются файлы за даты, отсутствующие в таблице; окно повторной обработки — 2 календарных дня (партиции перезаписываются целиком). Запуск ежедневно в 05:00 UTC; данные за дату D доступны не позднее 07:00 UTC дня D+1. При недоступности SFTP — 3 повтора с интервалом 20 минут, затем алерт.

## Контроль качества

Сверка числа строк файла и таблицы с учётом отбракованных, расхождение больше 0 — алерт; контроль наличия файла за каждую дату до 06:00 UTC. Ожидаемый объём — около 50 тысяч строк в день, хранение — 180 дней.
